Spread `field.props` for `name`, `ref`, `onFocus`, `onBlur` and `autoFocus`, then override `onChange` with `field.onChange`, which takes the value directly. `field.input` starts out `undefined`, so default it to `null` to keep the picker controlled.

The value is a `DateValue`, so validate it with a custom schema type. Submit the form empty to see the validation error.

## Install this example

With the [registry name](../../installation/) set up, this installs the example, the picker and only this form library:

```bash
npx shadcn@latest add @mrphilipp7/datetime-picker-formisch
```

Or add the dependencies yourself:

```bash
npm install @formisch/react valibot
```
