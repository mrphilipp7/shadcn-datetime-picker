Spread `field` onto the picker. It supplies `name`, `value`, `onChange`, `onBlur`, `ref` and `disabled`, so the picker is focused when validation fails.

The value is a `DateValue`, so validate it with a custom schema type. Submit the form empty to see the validation error.

## Install this example

With the [registry name](../../installation/) set up, this installs the example, the picker and only this form library:

```bash
npx shadcn@latest add @mrphilipp7/datetime-picker-react-hook-form
```

Or add the dependencies yourself:

```bash
npm install react-hook-form @hookform/resolvers zod
```
